## Задания

| Папка   | Задание                | Что использовано                                  |
|---------|------------------------|---------------------------------------------------|
| `task1` | Дневник погоды         | `new[]` / `delete[]`, три отдельные функции       |
| `task2` | Копилка                | указатели на функции, таблица команд, команда `double` |
| `task3` | Табло объявлений       | двумерный массив `char`, `Put` / `Text` возвращают `bool` |
| `task4` | Работа с указателями   | `int***` и `void*` (идея описана в комментарии в начале файла) |

## Как собрать и запустить

Из корня репозитория, на примере первого задания:

```
g++ -std=c++17 -Wall task1/main.cpp -o task1/main
./task1/main
```

Для остальных заданий нужно заменить `task1` на нужную папку. Все программы читают данные из стандартного ввода.
